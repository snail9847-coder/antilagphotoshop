# Проверки v0.2.0

GitHub Actions: Windows и Linux с Python 3.9 и 3.14. Проверяются компиляция `.py`/`.pyw`, self-test на 2000 циклов, все регрессионные тесты, задержки повторного запуска, кеш PID, ограничение уведомлений и локальная диагностика. Windows-специфичные проверки пропускаются на Linux. Приложение предназначено для Windows.

Отдельное Windows-задание проверяет настоящий трей, иконки, heartbeat, защиту от дублей и штатный выход, затем собирает ZIP, распаковывает его и запускает self-test из папки с пробелами и `!`.

## Из исходного архива

```bat
py -3 ci_tests.py
py -3 ci_tests.py --native
py -3 antilagphotoshop.py --self-test
py -3 build_release.py
```

Перед native-тестами закрой только antilagphotoshop через его меню, чтобы mutex работающей программы не мешал тестам. Сам Photoshop закрывать не требуется.

## Границы проверки

Регрессионные тесты заменяют запуск и завершение Photoshop mock-вызовами. Native-тесты запускают только guard/supervisor с `--no-auto-start`. Тест диагностики на Windows действительно читает ограниченный журнал Application внутри изолированной среды CI и записывает отчёт в временную папку. Тесты BAT используют безвредные Python-заглушки.

CI не запускает Adobe Photoshop, не открывает документы и не проверяет драйвер GPU или сохранение Adobe. Hosted Windows использует Windows Server, поэтому проверка на обычном Windows 10/11 остаётся отдельной задачей.

Задания ограничены десятью минутами. Постоянный тестовый workflow имеет только право чтения репозитория. Результаты, число пройденных/пропущенных тестов и ZIP доступны на вкладке Actions.
