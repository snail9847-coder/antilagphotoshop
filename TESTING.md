# Проверки antilagphotoshop

## Автоматические проверки

GitHub Actions запускает проверки при обновлении `main`, в pull request и вручную через `workflow_dispatch` после появления workflow в основной ветке.

- Windows и Linux, Python 3.9 и 3.14: компиляция `.py` и `.pyw`, встроенный self-test и 44 модульных/регрессионных теста.
- Windows, Python 3.14: 3 smoke-теста настоящих WinAPI, иконок, трея, heartbeat, защиты от дублей и завершения guard/supervisor.
- Windows-специфичные модульные тесты пропускаются на Linux. Linux-проверки не означают поддержку приложения на Linux.
- Постоянный workflow имеет только право чтения содержимого репозитория. Каждое задание ограничено десятью минутами.

Результаты находятся на вкладке **Actions** репозитория. Исторические неудачные прогоны могут содержать намеренное воспроизведение ошибок до исправления. Ориентируйтесь на проверки последнего коммита PR.

## Локальный запуск

Из папки проекта:

```bat
py -3 -m unittest -v test_antilagphotoshop test_regressions test_supervisor_regressions test_guard_lifecycle
py -3 antilagphotoshop.py --self-test
```

Проверка настоящего трея на Windows с доступным рабочим столом:

```bat
py -3 -m unittest -v test_windows_smoke
```

Перед smoke-тестами закройте только antilagphotoshop через его меню. Уже работающий экземпляр использует те же mutex и мешает тестам. Сам Photoshop закрывать не требуется.

## Безопасность и границы покрытия

Модульные тесты заменяют вызовы запуска и завершения Photoshop. Smoke-тесты запускают только guard/supervisor с `--no-auto-start`, значок может кратковременно появиться возле часов. Сам Adobe Photoshop тесты не запускают и не завершают.

CI не проверяет работу с настоящими документами Photoshop, диалоги сохранения Adobe, исправление чёрного холста, GPU-драйверы или восстановление документов. Успешный прогон не гарантирует отсутствие всех ошибок на конкретном компьютере.

## Добавленные регрессионные сценарии

`test_guard_lifecycle.py` проверяет:

- отмену запуска, если выход запрошен во время предварительной проверки;
- отмену автоматического запуска, если в это время включена пауза;
- запрет ручного запуска, пока выполняется принудительное закрытие;
- безопасный повторный вызов очистки до создания трея;
- возобновление автозапуска с первого клика после `--no-auto-start`;
- освобождение ресурса меню при исключении.

Команда принудительного закрытия по-прежнему требует двух подтверждений в интерфейсе. Автоматическое завершение Photoshop не добавлено.
