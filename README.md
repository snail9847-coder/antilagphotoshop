# antilagphotoshop

Небольшая программа для Windows 10/11 и Photoshop 2020: значок-молния в области уведомлений, наблюдение за процессом и ограниченные попытки восстановления после завершения. Python 3.9+, без сторонних библиотек.

**Это не ускоритель Photoshop и не гарантия от зависаний.** Программа не исправляет ошибки Adobe, видеодрайвера или плагинов. Она не умеет отличать обычный выход из Photoshop от аварии: при включённом автозапуске восстановит процесс в обоих случаях.

## Запуск

1. Установи Python 3.9 или новее, включив добавление в PATH.
2. Дважды нажми `run_antilagphotoshop.bat`.
3. Найди сине-фиолетовый значок с белой молнией возле часов (возможно, под стрелкой `^`).

Все файлы должны оставаться в одной папке. Сборка в EXE не требуется: это Python-приложение.

Нестандартный путь:

```bat
run_antilagphotoshop.bat --photoshop "D:\Adobe\Adobe Photoshop 2020\Photoshop.exe"
```

Также можно указать путь в `photoshop_path.txt` (UTF-8). Аргумент `--photoshop` имеет приоритет. Безопасный режим наблюдения без автоматического запуска Photoshop:

```bat
run_antilagphotoshop.bat --no-auto-start
```

Левый клик по значку запускает Photoshop, если он ещё не работает. Правый клик открывает меню. «Выход» закрывает только antilagphotoshop и его supervisor, не Photoshop.

## Безопасность и восстановление

- Проверка процесса примерно раз в 2 секунды; системные команды имеют тайм-ауты.
- Не более 3 автоматических попыток запуска за 10 минут. Ошибки пути и запуска тоже учитываются. После достижения лимита включается пауза; возобновление из меню сбрасывает лимит.
- Если состояние процесса неизвестно (ошибка `tasklist`), новый Photoshop не запускается.
- Запуски из меню и фоновой проверки сериализованы, чтобы не создавать дубликаты.
- Supervisor перезапускает только antilagphotoshop: максимум 8 сбоев за 15 минут, с задержкой 1–30 секунд. Контролируются и цикл сообщений интерфейса, и поток мониторинга.
- Отдельные mutex защищают приложение и supervisor от дублирования в одной сессии Windows. При невозможности создать mutex запуск отменяется.
- Журналы ограничены по размеру. Heartbeat записывается атомарно и использует монотонное время.
- Автоматического принудительного завершения Photoshop **нет**.

## Закрытие Photoshop

«Закрыть Photoshop (спросит про сохранение)» отправляет `WM_CLOSE` главному окну и ставит автозапуск на паузу. **Диалог сохранения может показать только сам отвечающий Photoshop**. Если он завис, команда не гарантирует появление диалога. Чтобы вернуть автоматическое восстановление, выбери «Продолжить автозапуск».

«Принудительно закрыть Photoshop» требует **двух подтверждений**, по умолчанию выбран ответ «Нет». После подтверждения выполняется `taskkill /F /IM Photoshop.exe`: завершатся все процессы Photoshop с этим именем, несохранённые изменения будут потеряны. Автозапуск ставится на паузу. Используй только как последнее средство.

## Чёрный холст и режим окна

«Убрать чёрный экран» сворачивает, восстанавливает и запрашивает перерисовку окна. Это может помочь при проблемах отображения, но не устраняет причину сбоя GPU. Окно, запущенное самим antilagphotoshop, переводится в обычный оконный режим; уже открытый Photoshop при простом запуске наблюдения не меняется.

«Развернуть Photoshop» максимизирует окно Windows, а не переключает внутренний полноэкранный режим Adobe.

Если проблема повторяется:

1. Включи автосохранение в Photoshop: Установки → Обработка файлов.
2. Обнови драйвер GPU; при необходимости попробуй отключить GPU в Установки → Производительность.
3. Проверь свободное место на системном и рабочем диске Photoshop, доступную RAM и сторонние плагины.

Внешняя программа не может сохранить документы после аварийного завершения Photoshop. Не заменяй ей обычное сохранение и резервные копии.

## Журналы

Оба журнала находятся в одной папке, доступной через меню приложения:

```text
%APPDATA%\antilagphotoshop\antilagphotoshop.log
%APPDATA%\antilagphotoshop\supervisor.log
```

Старые журналы предыдущего названия не удаляются и не переносятся автоматически.

## Проверки

В этой папке:

```bat
python antilagphotoshop.py --self-test
python -m unittest discover -v
```

Регрессионные тесты заменяют вызовы запуска/завершения Photoshop на границе ОС: реальный Photoshop они не запускают и не закрывают. Windows smoke-тест запускает само приложение с `--no-auto-start`, проверяет настоящий трей, загрузку ICO, меню, heartbeat, защиту от дублей и штатный выход supervisor. При этом значок приложения может кратковременно появиться возле часов.

## Иконка

`antilagphotoshop.ico` — оригинальная белая молния на сине-фиолетовом фоне, 7 размеров: 16, 24, 32, 48, 64, 128 и 256 px. `antilagphotoshop.png` — крупное превью. Генерация без библиотек:

```bat
python build_icon.py
```

## Исправления

- 64-битные сигнатуры WinAPI для окон, меню, иконок, сообщений и mutex; освобождение ресурсов.
- Учёт неудачных запусков в ограничителе; защита от гонок и запуска при неизвестном состоянии процесса.
- Чтение повреждённого файла пути без падения, поддержка UTF-8 BOM.
- Отсутствие блокирующего запуска Photoshop в обработчике клика по трею; статус берётся из мониторинга.
- Пауза после закрытия Photoshop из меню, настоящий `/F` и два подтверждения для опасной команды.
- Проверка heartbeat на повреждённые/нечисловые значения, отдельный файл supervisor и контроль UI.
- Восстановление значка после перезапуска Explorer.
- Исправлена проверка наличия `pythonw` в BAT: прежняя вложенная проверка использовала устаревшее `%errorlevel%`.
