# antilagphotoshop v0.2.0

Программа наблюдения за Photoshop 2020 для Windows 10/11. Python 3.9+, без сторонних библиотек. Предварительная версия.

## Запуск

1. Скачай ZIP из Releases и полностью распакуй. BAT нельзя запускать внутри архива.
2. Если старая версия работает, закрой только antilagphotoshop через значок → «Выход».
3. Нужен установленный Python с Python Launcher или добавлением в PATH. Для новой установки рекомендуем Python 3.14.
4. Проверь `photoshop_path.txt`: там указан `E:\Adobe Photoshop 2020\Photoshop.exe`. При необходимости замени путь на свой и сохрани в UTF-8.
5. Открой `run_antilagphotoshop.bat`. Значок молнии появится возле часов, возможно под стрелкой скрытых значков.

Оставь все файлы рядом. EXE собирать не нужно. В исходном архиве дополнительно есть тесты; в архиве `windows-python.zip` находятся только файлы для использования.

Нестандартный путь можно задать аргументом с приоритетом над файлом:

```bat
run_antilagphotoshop.bat --photoshop "D:\Adobe\Adobe Photoshop 2020\Photoshop.exe"
```

Только наблюдение без автоматического запуска:

```bat
run_antilagphotoshop.bat --no-auto-start
```

## Что изменилось в v0.2.0

- Проверка процессов примерно раз в 5 секунд вместо 2. Проверка окон использует свежий список PID из мониторинга; перед запуском всегда выполняется новая проверка процесса.
- После обнаруженного завершения Photoshop до автоматического запуска проходит не менее 10 секунд. Повторные попытки разнесены задержками 10, 20 и 40 секунд; общий предел задержки 60 секунд. Рабочий поток не спит на время этой задержки и продолжает наблюдение.
- Сохраняется лимит 3 автоматических попыток за 10 минут. Ошибки пути и запуска тоже считаются. После лимита включается пауза. Ручной запуск может обойти ожидание и сбросить лимит.
- Программа больше не переключает окно Photoshop автоматически после запуска. Команды окна доступны только через меню.
- Во время работы Photoshop свободные RAM и место на системном диске, диске TEMP и диске установки проверяются примерно раз в 30 секунд. При RAM меньше 400 МБ или месте меньше 2048 МБ появляется предупреждение, не чаще одного раза в 5 минут. Программа ничего не закрывает и не очищает. Диск установки не обязательно является рабочим диском Photoshop (scratch disk).
- Для диагностики добавлен отдельный `collect_diagnostics.bat`.

## Управление

Левый клик по значку запускает Photoshop, если он отсутствует. Правый клик открывает меню. «Выход» закрывает только antilagphotoshop и supervisor.

Обычный запуск BAT включает автозапуск. Программа не различает нормальное закрытие Photoshop и аварийное: в обоих случаях может открыть его снова после задержки. Чтобы этого не происходило, выбери «Пауза автозапуска» или используй `--no-auto-start`.

«Закрыть Photoshop (спросит про сохранение)» отправляет запрос главному окну и ставит автозапуск на паузу. Сохранение предлагает только сам отвечающий Photoshop.

«Принудительно закрыть Photoshop» требует двух подтверждений с ответом «Нет» по умолчанию. Команда `taskkill /F /IM Photoshop.exe` завершает все процессы с этим именем, несохранённые изменения будут потеряны. Только для крайнего случая.

«Убрать чёрный экран» вручную сворачивает, восстанавливает и запрашивает перерисовку окна. Это не изменение драйвера GPU. «Развернуть Photoshop» максимизирует окно Windows, не переключая внутренний режим Adobe.

## Локальная диагностика

Запусти `collect_diagnostics.bat`. Окно покажет путь к двум файлам отчёта в новой папке:

```text
%APPDATA%\antilagphotoshop\diagnostics\report-...\diagnostics.txt
%APPDATA%\antilagphotoshop\diagnostics\report-...\diagnostics.json
```

Отчёт содержит сведения об ОС/Python, свободной RAM и дисках, путь Photoshop, последние 100 КБ каждого журнала программы и отфильтрованные события Photoshop из журнала Windows. Поиск ограничен последними 200 событиями Application с ID 1000/1001/1002 за 7 дней, затем фильтруется по Photoshop. Это не полный архив сбоев. Ошибки чтения журнала отмечаются в отчёте.

Ничего автоматически не отправляется. Отчёт может содержать личные пути и текст событий: проверь его перед отправкой кому-либо. Не публикуй отчёт в открытом репозитории без проверки.

## Безопасность

Программа не меняет настройки Photoshop, плагины, драйверы, реестр или документы. Не удаляет файлы восстановления, не выполняет «очистку RAM», не добавляет автоматическое принудительное закрытие. Перед запуском проверяет доступные ресурсы. При неизвестном состоянии процесса новый Photoshop не запускается.

Supervisor восстанавливает только antilagphotoshop, контролируя heartbeat интерфейса и потока наблюдения. Максимум 8 сбоев за 15 минут; отдельные mutex защищают от дублей в одной сессии Windows.

Это наблюдение и диагностика, не исправление внутреннего кода Adobe. Сохраняй документы и делай резервные копии. Проверка настоящего Photoshop, твоих документов и GPU выполняется отдельно от CI.
